# Project Instructions

Before planning, implementing, reviewing, or modifying this project, read
[`TECHNICAL_SPEC.md`](TECHNICAL_SPEC.md) in full.

`TECHNICAL_SPEC.md` is the project source of truth for product scope,
architecture, data contracts, investigation behavior, explainability,
acceptance criteria, and the hackathon delivery plan.

When a task conflicts with the specification:

1. Follow the user's latest explicit instruction.
2. Record any intentional deviation in the relevant change or handoff.
3. Do not silently expand the MVP scope.

All financial arithmetic, normalization, matching, and evidence retrieval must
remain deterministic. AI-assisted nodes may interpret retrieved evidence and
write explanations, but must never invent financial facts.
